Data scope & methodology
PR Cycle Time

Average time in hours from a pull request's created_at to its merged_at timestamp. Only merged PRs are counted — closed-but-unmerged PRs are excluded. Sourced from up to 100 of the most-recent closed PRs via the GitHub REST API.

PR Frequency

Merged pull requests per day, calculated from the 100-PR fetch window. The span is measured from the merged_at timestamp of the oldest to the newest merged PR in the set. The total merged PR count is divided by that span in days to produce a daily average.

Stale Branches

Count of non-default branches whose most-recent commit's committer.date is older than 90 days. The default branch is always excluded. Branches with no resolvable commit date are skipped rather than counted as stale.

Contributors

Unique commit authors identified across the fetched commit window. Each contributor is deduped by their GitHub author.login when available, falling back to the committer.name string. The sparkline shows weekly unique-contributor counts over the past 12 weeks.
