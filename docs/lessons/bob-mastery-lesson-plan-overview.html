The Six Lessons

Lesson 01
How Bob Thinks: The Core Mental Model
What Bob actually is, how it reasons, and why it works the way it does
~20 min
What you'll understand
  • Why Bob is called an "SDLC partner" and what that actually means in practice
  • The context window: what's in it, how it fills up, and why it matters for cost and quality
  • The approval loop: how Bob proposes, you approve, and why this architecture exists
  • What "agentic AI" means vs. a simple chatbot — and how to explain it to stakeholders
SDLC partner Context window (270k tokens) Tool execution loop Approval model Bobcoins intro
Lesson 02
Modes & Tools: Bob's Operating System
The three built-in modes, what each can and cannot do, and every tool category
~25 min
What you'll understand
  • The exact tool permissions each mode grants — and why Agent can execute but Ask cannot
  • When to use Plan → Agent vs. going straight to Agent
  • All 8 tool categories: Read, Write, Execute, MCP, Skill, Subagent, Todo, Mode
  • How switching modes mid-task changes what Bob is allowed to do
Agent / Ask / Plan Tool permission matrix Read tools Write tools Execute tools Mode switching
Lesson 03
Skills & Subagents: Teaching Bob to Specialize
How to extend Bob's knowledge with skills and delegate parallel work with subagents
~25 min
What you'll understand
  • What a skill is architecturally — SKILL.md format, frontmatter, file structure
  • Global vs. project-scoped skills and how priority resolution works
  • How subagents differ from subtasks (silent background vs. visible conversation)
  • The three conditions that must all be true before Bob spawns a subagent
  • fork_context: when conversation history gets passed and why it matters
SKILL.md format Skill scoping Subagent types (explore / general) Subtasks vs. subagents fork_context
Lesson 04
Configuring Bob: Modes, Rules & MCP
Custom modes, the rules system (AGENTS.md, .bob/rules/), and MCP integrations
~25 min
What you'll understand
  • Every field in a custom mode YAML — slug, roleDefinition, groups, fileRegex
  • The full rules hierarchy: global → workspace → mode-specific → AGENTS.md
  • What MCP is (the USB-C analogy), client-server architecture, and transport types
  • How to assess whether an MCP server is worth adding and what security questions to ask
custom_modes.yaml fileRegex permissions AGENTS.md Rules hierarchy MCP protocol .bobignore
Lesson 05
Power Features: The Developer Workflow Toolkit
Rollback, Bob tips, literate coding, context mentions, code reviews, and auto-approve
~25 min
What you'll understand
  • How rollback works under the hood (shadow git repos) and when to use it vs. undo
  • The Bob tips quality metrics — what thresholds trigger a suggestion and what they measure
  • What literate coding is and why it's a different interaction model than chat
  • All @mention types: files, folders, @problems, @terminal, @git-changes, @URL
  • The auto-approve settings matrix and the security tradeoffs of each toggle
Rollback Bob tips Literate coding Context mentions (@) Code reviews PR generation Commit messages Auto-approve
Lesson 06
Cost, Security & Scale: The PM Lens
Bobcoins, Bobalytics, enterprise features, the full security threat model, and Bob Shell
~20 min
What you'll understand
  • How Bobcoins work as a unified billing metric across different underlying models
  • What Bobalytics tracks, what it deliberately hides (individual vs. team-level data)
  • Enterprise plan capabilities: shared Bobcoin pools, admin dashboards, team management
  • The full security threat model: prompt injection, context poisoning, MCP risks
  • What Bob Shell is and when it's more appropriate than the IDE extension
Bobcoins Bobalytics Enterprise plan Context poisoning Security guidance Bob Shell API keys
